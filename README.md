# Jude Andrade — Design Researcher

Portfolio of research on how people make their way through products and public services.

**Live portfolio:** https://judeandrade013.github.io/

## Selected work

- Taxi and vehicle-for-hire regulatory redesign (Chapter 239)
- KOALA product research and listing-flow improvement
- Public digital services and seven-resource facility booking workflows
- Memorial Park flood-mitigation study and grant eligibility
- Village fee schedule modernization and Board adoption

The civic projects were independently driven in-house, with input from municipal staff, engineers, counsel and specialist vendors when relevant. Case studies distinguish shipped services, tested systems, adopted decisions and future work.

## About the site

Hand-built static HTML, CSS and JavaScript, hosted on GitHub Pages. The homepage is `index.html`; each case study is its own page in `work/`, with the same four stages (01 Context, 02 Approach, 03 Decisions, 04 Outcome), a numbered section rail, and a reading-depth control (Quick Look / Full Story / Deep Dive) where a case is long enough to need one. The About page is `about.html`; the résumé is `resume.html`, with `resume.pdf` as the download. Shared styles are in `site.css`, where all colours are tokens with one light and one dark set; `site.js` runs the theme toggle, header, mobile menu and case-study tools. `DESIGN.md` documents the type scale, colour, spacing, breakpoints and components.
